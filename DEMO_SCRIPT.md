# 🎬 Demo Script (30 seconds)

## Opening (5 seconds)
**Show:** Extension icon in Chrome toolbar
**Say:** "Companies waste billions on unnecessary meetings. This Chrome extension makes the cost visible."

## Calculator Demo (10 seconds)
**Do:** 
- Click extension icon
- Show pre-filled: 10 attendees, $75/hour, 30 minutes
- Click "Calculate Cost"

**Say:** "This 30-minute meeting with 10 people costs $375. That's $19,500 per year if it happens weekly."

## Timer Demo (10 seconds)
**Do:**
- Click "Start" on live timer
- Let it run for 5-10 seconds
- Show cost accumulating

**Say:** "The live timer shows costs accumulating in real-time during meetings. Watch the dollars add up."

## Closing (5 seconds)
**Say:** "Simple tool, massive impact. Make every meeting count."
**Show:** GitHub repo link on screen

## Recording Tips

✅ **Use clear audio** - built-in mic is fine
✅ **Show cursor** - helps viewers follow along
✅ **Zoom in** on important numbers
✅ **Speak clearly** but naturally
✅ **Keep it under 3 minutes** (Devpost requirement)

## Recording Tools

- **Windows:** Win + G (Game Bar)
- **Online:** Loom.com (free, easy)
- **Phone:** Just record your screen
- **OBS:** Free, professional quality
