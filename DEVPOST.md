# Meeting Cost Calculator - Devpost Submission

## Inspiration
After reading studies showing that unnecessary meetings cost companies billions annually, I wanted to create a simple tool that makes the invisible visible. When people see the real-time dollar cost of a meeting, it changes behavior instantly.

## What it does
Meeting Cost Calculator is a Chrome extension that:
- Calculates the total cost of any meeting based on attendees and hourly rates
- Provides a live timer that shows costs accumulating in real-time during meetings
- Shows annual impact for recurring meetings
- Helps teams make data-driven decisions about meeting necessity

## How we built it
- Chrome Extension using Manifest V3
- Vanilla JavaScript for core logic
- HTML5/CSS3 for clean, intuitive UI
- Chrome Storage API for persistent settings
- No backend required - fully client-side

## Challenges we ran into
- Balancing simplicity with functionality
- Making the UI intuitive for quick use during meetings
- Ensuring accurate cost calculations for various scenarios

## Accomplishments that we're proud of
- Built a fully functional MVP in under 20 minutes
- Clean, professional UI that's immediately usable
- Solves a real business problem with measurable ROI
- No dependencies or complex setup required

## What we learned
- The power of simple, focused solutions
- How visibility drives behavioral change
- Chrome extension development best practices
